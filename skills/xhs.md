## 小红书内容搜索技能

小红书是真实游客笔记最密集的来源，经本机 xiaohongshu-mcp 服务接入。**除系统自动的随机点赞外只读**：搜索、阅读由你发起；发布/评论/关注等写操作不存在。

### 关于自动点赞

精读笔记时，系统会以约 5% 的概率**自动顺手点赞**（代码行为，与你无关，无需调用也无法控制）。看到工具结果末尾的「已顺手为该笔记点赞」时不必向用户特别说明，它属于正常浏览行为。

### 定位（只做四件事）

| 用途 | 说明 |
|------|------|
| **成形攻略** | 真实游客的成行路线、天数节奏、顺序安排（阶段2 划 part 的重要输入） |
| **景点大全（时效性强）** | 周边必去清单、新开/关闭/预约政策变动——比官方信息更新快，但须交叉验证 |
| **真人评价** | 景点值不值得去、避坑踩雷、排队/人流实况（阶段3 甄选、阶段4 查证防瞎改） |
| **美食推荐** | 本地人推荐、必吃清单（完整攻略在阶段1统一预搜，阶段3只结合动线使用） |

**酒店不用小红书查**：酒店一律按 `skills/hotel.md` 的渠道与标准搜索。唯一例外：高价酒店且客户预算特别充足时，可搜「{酒店} 入住体验」作真实体验参考，但筛选标准仍以 hotel.md 为准。

### 两个工具

```
// 1. 搜索笔记（返回列表，每条带 feed_id 与 xsec_token）
search_xhs({
    "keyword": "壶口瀑布 攻略 避坑",
    "sort_by": "最多点赞"        // 可选：综合|最新|最多点赞|最多评论|最多收藏
    // "note_type": "图文"      // 可选：不限|视频|图文
    // "publish_time": "半年内"  // 可选：不限|一天内|一周内|半年内
})

// 2. 读笔记详情 + 评论（feed_id 与 xsec_token 必须来自 search_xhs 的返回，配对使用）
read_xhs_note({
    "feed_id": "…",
    "xsec_token": "…"
    // 系统自动限制评论条数（随机 3~8 条）；深挖模式可显式传 load_all_comments: true（封顶 10 条）
})
```

### 何时用（与 search_web 分工）

| 场景 | 用什么 |
|------|--------|
| 交通方案、官方信息（门票/开放时间/车次）、**酒店** | `search_web` |
| 成形攻略、景点大全（时效）、真人评价、美食推荐 | `search_xhs`（优先） |

- 阶段2 划 part：搜「{目的地} 攻略 路线」「{目的地} X天 行程」看真实成行路线
- 阶段1 美食全局预搜：路线和城市确定后搜「{城市} 美食 本地人」；阶段3 景点甄选搜「{景点} 值得去吗」，深挖时读笔记+评论区
- 阶段4 查证：修改方案前搜「{景点} 避坑」看最近游客反馈防瞎改（**酒店除外**，见「定位」节）

### 使用纪律

1. **feed_id 和 xsec_token 配对传递**，都来自同一条 search_xhs 结果；xsec_token 过期或报错 → 重新 search 一次拿新的
2. **评论区是金矿**：预约方式变更、天气影响、涨价、安全提示、本地人反驳——高赞笔记可开启深挖模式读评论区（系统会自动限制条数）
3. **交叉验证**：小红书笔记有广告与滤镜成分，关键事实（价格/时间/预约）仍以 search_web 的官方信息为准
4. **信息时效**：引用笔记时留意发布时间（publish_time 筛选「半年内」可取新鲜内容），告诉用户信息可能有变动
5. **服务不可用不阻塞**：工具报「服务未运行/未登录」时，如实告知用户并退回 search_web 继续工作

### 拟人使用纪律（防风控，必须遵守）

小红书风控对「机器节奏」敏感，账号会被警告甚至封禁。**所有调用都会被系统自动随机减速，这是刻意的，不要试图绕过或连续重试。** 你要配合做到：

1. **搜索词多样化**：关键词要像真人随口搜的——同义改写、长短混合（「平遥古城 两天怎么玩」「平遥 通票 值不值」），**不要每次都用同一个模板**（如反复「XX攻略 必去」）
2. **总量克制**：一次规划任务搜索 **≤3 个关键词**；搜出来的列表先看标题和数据，**只挑 2~3 篇值得深读**——大多数笔记看一眼列表就够了（这就是真人的「刷到但没点开」）
3. **评论少的不值得读**：互动数据里评论数寥寥的笔记，别为挖评论区单独读详情
4. **不要连续重试**：调用失败（限流/未登录）就换 search_web，过几轮再说
