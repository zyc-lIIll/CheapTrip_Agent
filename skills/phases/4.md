# 阶段4：整体调整 + 预算统计

所有 part 的初版方案都已完成（在会话记忆里）。本阶段从「分块拼图」切换到「整张图」：

1. **敲定所有大交通**：
   - 往返大交通（出发地⇌目的地）：3-5 个选项，班次/时段核实
   - part 之间每段城际交通：具体车次/航班/时长/票价；直达不佳按 `skills/special.md` 换乘策略找中转
   - 核对各段衔接：到达时段→当天还能安排什么；出发时段→最后一天能玩到几点
2. **调整 part 顺序与整体节奏**：串总行程 `出发地 → part A(X晚) → part B(X晚) → 返程`，顺序不合理就调
3. **卡总预算**：汇总所有费用（大交通/当地交通/住宿/门票/餐饮/备用金/总计）对照客户预算：
   - 超了 → 给削减选项（砍景点/降住宿档/换交通方式）让客户选
   - 有富余 → 可建议升级一两项
4. 生成预算明细表，有优惠分别标注不同人群人均

## 调整纪律（不许瞎改）

调整涉及换酒店/换景点/换交通时，**必须按对应技能文档的搜索策略重新查证**，不许随手改：

- **换酒店（最重要）**：严格按 `skills/hotel.md`（评分门槛/品牌优先/评价红线）重新搜索推荐，给出真实完整酒店名，绝不编造；**酒店不用小红书查**（唯一例外：高价酒店且预算特别充足时，可搜「{酒店} 入住体验」作参考，筛选标准仍按 hotel.md）
- **换景点**：按 `skills/discovery.md` 搜索验证门票/开放时间；`search_xhs` 可用时搜「{景点} 避坑」看最近游客反馈
- **换火车/交通**：按 `skills/special.md` 换乘策略查证，不编车次

有联动调整（改行程影响住宿、改交通影响节奏）就回对应 part 微调，不要无限循环。

**本阶段完成**：整体方案与预算经客户认可后，调 `set_phase(5)` 进入完整攻略。
